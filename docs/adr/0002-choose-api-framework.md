# ADR 0002 — Choix du framework API

## Status

Proposed

## Context

pyBudo nécessite une API HTTP pour permettre au frontend de communiquer
avec le backend.

Le framework Python n'est pas encore définitivement choisi.

## Decision

Aucune décision définitive n'est prise à ce stade.

## Critères d'évaluation

Le framework sera évalué selon :

- simplicité ;
- maintenabilité ;
- typage ;
- testabilité ;
- documentation ;
- performances ;
- écosystème ;
- compétences disponibles dans l'équipe ;
- facilité de déploiement.

## Alternatives

Les différents frameworks Python répondant au besoin seront comparés
avant décision.

## Consequences

Le choix définitif devra être documenté dans cet ADR avant le démarrage
de l'implémentation dépendante du framework.
