# Persona utilisateur — pyBudo

## Persona principal

**Nom :** Thierry

**Profil :** débutant en programmation souhaitant apprendre Python
par la pratique.

**Niveau :** débutant à débutant intermédiaire.

## Objectifs

Thierry souhaite :

- comprendre Python ;
- pratiquer régulièrement ;
- savoir immédiatement si son code fonctionne ;
- comprendre ses erreurs ;
- progresser progressivement.

## Difficultés

Thierry peut :

- comprendre une notion sans savoir l'appliquer ;
- faire des erreurs de syntaxe ;
- ne pas comprendre pourquoi un test échoue ;
- avoir besoin d'indices sans recevoir directement la solution.

## Contexte

Thierry souhaite pouvoir pratiquer Python sans devoir installer et
configurer lui-même un environnement complexe.

## Besoins

- exercices courts ;
- énoncés clairs ;
- éditeur de code ;
- exécution simple ;
- feedback immédiat ;
- progression visible.

## Hypothèses à valider

Ce persona constitue une hypothèse initiale.

Il devra être confronté à de vrais utilisateurs avant de considérer
ces caractéristiques comme validées.
