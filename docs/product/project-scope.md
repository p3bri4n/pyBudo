# Cadrage du projet — pyBudo

## Vision

pyBudo est une plateforme d'apprentissage de la programmation Python
basée sur la pratique.

L'utilisateur doit pouvoir apprendre une notion, résoudre un exercice,
exécuter son code et comprendre immédiatement le résultat.

## Problème

Les débutants peuvent connaître la théorie sans savoir la transformer
en compétence pratique.

pyBudo cherche à favoriser l'apprentissage par la pratique et le
feedback immédiat.

## Utilisateur cible

Le persona principal est un débutant ou développeur en apprentissage
de Python.

Voir [Persona](./persona.md).

## MVP

Le MVP doit permettre de :

- consulter un exercice ;
- lire son énoncé ;
- écrire une solution Python ;
- soumettre la solution ;
- exécuter le code ;
- valider la solution ;
- recevoir un feedback.

## Hors périmètre initial

- fonctionnalités sociales ;
- classement ;
- certificats ;
- support de plusieurs langages ;
- personnalisation avancée ;
- fonctionnalités communautaires complexes.

## Contraintes

- le code utilisateur est considéré comme non fiable ;
- l'exécution de son code doit être isolée ;
- les tests doivent être automatisés ;
- le projet doit rester maintenable.

## Critère de réussite

Un utilisateur doit pouvoir résoudre un exercice simple de bout en bout
sans intervention manuelle d'un développeur.
