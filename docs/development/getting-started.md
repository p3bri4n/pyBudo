# Getting Started

## Prérequis

Installer :

- Git ;
- Python ;
- un environnement virtuel Python.

## Cloner

```bash
git clone git@github.com:p3bri4n/pyBudo.git
cd pyBudo
```

Toujours partir de dev: 
```bash
git checkout dev
git pull
git checkout -b 15/feature/exercise-validation
```
Puis développer et créer une PR vers dev
